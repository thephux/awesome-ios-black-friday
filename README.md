## ➕ How to add your deal

1. Read [CONTRIBUTING.md](CONTRIBUTING.md).
2. [Edit the README](https://github.com/thephux/awesome-ios-black-friday/edit/main/README.md) and add **one row at the end** of the right category table under the current year.
3. Open a pull request and tick the checklist.

Row format:

```
| [App Name](https://apps.apple.com/app/id000000000) | iOS, macOS | One line on what it does. | 💸 ♾️ **50% OFF Lifetime** · $39.99 → $19.99 · code `BF26` | Nov 20 – Dec 1 |
```
